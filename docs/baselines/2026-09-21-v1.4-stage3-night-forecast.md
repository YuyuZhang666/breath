# v1.4 阶段 3：NightForecast 与 TailEstimator

日期：2026-09-21

## 范围

本阶段完成整夜风险预测、短视野后的尾部估计、风险驱动的 Director
以及动态最低安全金币储备。未提前实现阶段 4 的 ComputeGovernor。

夜间链路调整为：

```text
NightForecast
  -> Phase 2.5 确定性联合火控
  -> SAFE: 直接输出
  -> WATCH: Phase 3 Lite
  -> CRITICAL / LETHAL: Phase 3 Full
  -> Phase 2 兜底
```

## 关键接口变化

- `RiskLevel`：`unknown`、`safe`、`watch`、`critical`、`lethal`。
- `NightForecast`：记录预计整夜来袭伤害、有效防御、未来火力、风险比、
  生存余量、最早致死回合、完整性和不确定性原因。
- `ForecastUpdateKind`：首个夜间回合和关键事件执行 `full`，普通回合执行
  O(资产数) 的 `incremental`，白天执行 `rebased_day`。
- `TailEstimate`：把 Phase 3 的 2～4 回合精确模拟补足到天亮，并将投影结果
  写入生存证书。
- `CheapestSafePlan`：只枚举规则已确认且效果可计算的安全方案；安全计划动作可
  精确使用预留金币，其他动作不得消耗储备。

## 风险与重算

- `SAFE`：风险比小于 0.55 且生存余量非负。
- `WATCH`：风险比位于 [0.55, 0.85) 且生存余量非负。
- `CRITICAL`：风险比至少 0.85 或生存余量为负。
- `LETHAL`：预测基地会在 1～2 回合内死亡。
- 首夜、模型或天数变化、资产损失、伤害偏差至少 50%、波次突变、新机器人、
  紧急物品、相关火箭就绪或连续两次攻击无效会触发全量重算。
- 其余夜间回合增量更新；进入白天后重置即时致死判断，同时保留上一夜风险用于
  补墙和金币储备。

## 保守估计与未知规则

- 来袭估计使用机器人攻击力、预计攻击回合和到达概率；已观测机器人按到达概率 1
  处理。
- 有效防御只计基地和最小关键墙屏障，不重复计算多层墙。
- 未来火力只计当前确定性联合火控能够保证消灭目标后避免的后续伤害。
- 未验证的物品、维修和升级治疗效果不计入恢复量。
- 默认不假定当前可见机器人就是整夜完整名单；D3+ 没有真实日志校准来源时标记
  `d3_calibration_unavailable`，不会伪造系数或把未知风险声明为安全。
- 真实对局 JSON 无需上传；D3+ 改善当前只由合成确定性用例验证，真实胜率与调用率
  留给用户侧聚合遥测验收。

## 动态金币储备

- 已安全时储备为 0。
- 找到可验证的最低安全方案时，储备等于方案成本，且仅方案中的精确动作可以使用。
- 预测已知但找不到安全方案时，保留当前全部金币。
- 预测不可用时保持既有 75/100 等保守配置，不猜测未知规则。
- `DESPERATION` 下储备为 0，避免储备阻塞即时求生。

## 性能

确定性 `phase3_night_request.json`，控制器分配在计时外准备，60 次运行：

| 项目 | P50 | P95 | 目标 |
|---|---:|---:|---:|
| NightForecast（缓存控制器分配） | 1.01ms | 1.40ms | 增量回合低开销 |
| Phase 3 Lite + TailEstimator | 3.38ms | 4.08ms | P95 <5ms |
| Phase 3 Full + TailEstimator | 5.97ms | 6.51ms | P95 <12ms |

阶段 2 的 Lite/Full P95 分别为 1.95ms/4.37ms；本阶段增加整夜尾部证书后仍满足
预算。首次整回合夜间路径仍包含控制器冷分配，定向测试约 23ms；重复请求由会话缓存
直接返回。
