# v1.4.6 Wall recovery memory

## Scope

This increment makes daylight fortification stable across rounds and separates
first-time construction from rebuilding walls destroyed during a previous
night. It builds on the v1.4.5 staged opening and does not enable repair of a
damaged-but-living wall.

## Daily layout memory

Match memory now retains:

- the current fortification day;
- one fixed threat-direction anchor for that day;
- every friendly wall position observed during the match.

At the first daylight observation, the anchor uses the previous night threat
positions. If no threat history exists, it uses current targeted robots and
then the map center as a deterministic fallback. Later observations cannot
change the anchor until the next day. Wall layout therefore does not oscillate
when transient robots appear from another direction.

Historical wall positions are bounded to 256 entries and reset with match
rollback or side change.

## Rebuild policy

A planned wall site that was observed previously but is now empty is a rebuild
gap. Rebuild gaps:

- open the wall gate even if first-day weapons were also destroyed;
- are ranked before never-built wall gaps before candidate truncation;
- receive a 60-point rebuild boost;
- therefore outrank remaining core weapon construction, including ordinary
  non-critical rebuilds.

Never-built walls preserve the v1.4.5 order: critical opening walls outrank
remaining weapons, while ordinary infill remains below them.

## Telemetry

The turn record adds new-wall and rebuild-wall gap counts, historical wall
count, anchor day, and anchor threat count. `wall_plan_stage` now distinguishes
`opening_critical`, `critical_rebuild`, `daily_rebuild`,
`complete_core_weapons`, and `daily_infill`.
